# 지형·도시 분위기 수정

- 사막의 각진 지층 절벽/원형 고지대 메시 그룹을 비활성화하고, 그랜드캐니언 작업 전 TerrainData를 복원했습니다. 원래의 구불구불한 모래 골짜기와 기존 바위 지형을 살렸습니다.
- 기존 높이에 부드럽게 섞이는 넓은 둔덕 4구역을 추가했습니다. 실제 사용 중인 두 이동 경로에서 9m 이내의 지형 높이는 이 둔덕 조정에서 제외했습니다. 장식·선인장은 복원된 지면에 맞춰 재배치했습니다.
- 도시 쉘터 중앙 바닥의 `Shelter_MedicalCross_H/V`를 숨겼습니다. 구급 텐트의 의료 표시는 유지했습니다.
- 목표 위치에 2층 콘크리트 GP형 지휘·경계 건물을 추가했습니다. 관측창, 모래주머니, 평지붕, 출입구, 계단, 안테나, 투광등과 한글 표지판을 구성했습니다.
- 제공된 기존 건물 32개에 도시 건물 28개를 추가하고, 외곽 고층 8개를 촘촘한 창문 외관으로 교체했습니다. 기존 건물까지 총 68개가 밀집한 배치를 이룹니다(기존 원경 스카이라인 제외).
- 회색·갈색·베이지 외벽, 반복 창호, 평지붕과 옥상 설비, 아스팔트·타일 보도 재질로 참고 이미지의 도시 분위기를 반영했습니다. 로봇이나 UI는 참고 대상에서 제외했습니다.
- 중앙 쉘터 주변에는 건물을 밀어 넣지 않고 네 진입로와 차량·검문 시설을 유지했습니다.

재적용 메뉴: `Tools/AI Defenders/Environment Expansion/8 Natural Canyon And Urban GP`.
수정 전 씬 및 사막 TerrainData는 `Before`에 보관했습니다.

검증: Unity 컴파일/콘솔 오류 없음. 사막 145개, 도시 212개 이동 경로 지면 샘플에서 새 물체가 길을 막는 지점 없음. 스포너·목표·경로·카메라 Transform 서명은 적용 전후 동일합니다. 전체 전투의 난이도 검증은 별도로 필요합니다.

요청에 따라 이번 수정본은 사진을 촬영하지 않았습니다. `Docs/CanyonCityUpgrade/Photos`는 이전 수정 당시 사진입니다. 사막 선택 화면에는 보관된 기존 지형 미리보기를 복원했습니다.
