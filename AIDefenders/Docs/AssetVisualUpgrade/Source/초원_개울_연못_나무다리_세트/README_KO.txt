AI Defenders — 초원 개울·연못·나무다리 세트

구성: 6종 / 전체 2,942 삼각형
StreamStraight: 직선 개울 706 삼각형, 4×4 타일
StreamCurve: 90도 곡선 개울 706 삼각형, 4×4 타일
Pond: 연못 730 삼각형, 4×4 타일
WoodenBridge: 난간과 양쪽 경사로가 있는 나무다리, 288 삼각형
SteppingStones: 징검돌 4개 묶음, 96 삼각형
Reeds: 갈대 8줄기 묶음, 416 삼각형

Unity 적용
1. Assets/AIDefendersMeadowWater 폴더를 프로젝트 Assets에 복사합니다.
2. 컴파일 후 Tools > AI Defenders > Create Meadow Water를 실행합니다.
3. Assets/AIDefendersMeadowWaterGenerated 아래 개별 프리팹, 메시·재질,
   MeadowWaterSample.prefab이 생성됩니다. 반복 실행은 새 폴더에 저장합니다.
Built-in 및 URP 재질을 지원합니다. HDRP는 별도 재질 설정이 필요합니다.
이 패키지는 다른 초원 패키지에 의존하지 않습니다.

타일 크기와 연결
1 Unity 단위=1m 기준입니다. 지면 X/Z=-2~+2, 잔디 윗면 Y=0,
물 표면 Y=-0.18, 흙 밑면 Y=-0.45입니다. 물길 폭은 1.5입니다.
4단위 위치 스냅과 Y축 90도 회전으로 물길을 연결할 수 있습니다.
회전 전 로컬 기준 N=+Z, E=+X, S=-Z, W=-X입니다.
StreamStraight 물길 연결 방향: N·S
StreamCurve 물길 연결 방향: W·S
Pond는 독립 연못이며 외곽에 물길 연결구가 없습니다.
곡선과 둑은 0.25단위 격자 형태로 표현합니다.
닫힌 잔디 경계는 기존 초원 평지 타일과 높이가 맞습니다.

나무다리
다리는 X축 방향으로 물길을 가로지릅니다. 직선 개울과 같은 원점에 배치하세요.
전체 길이는 약 4.4, 폭은 1.8이며 양쪽 램프가 타일 바깥으로 약 0.2씩 나옵니다.
양쪽에 충분한 평지를 배치하세요. 램프 끝 바닥 Y=0, 상단 보행면은 약 Y=0.5입니다.
통과 가능한 실제 폭은 난간·기둥 사이 약 1.59이므로 캐릭터 크기에 맞게 조절하세요.
다리는 고정된 메시이며 움직임이나 파괴 애니메이션은 없습니다.

징검돌과 갈대
징검돌 묶음의 로컬 바닥은 Y=0, 돌 윗면은 Y=0.28입니다.
개울에서는 루트 Y=-0.18에 배치하면 윗면이 지면보다 0.1 높게 나옵니다.
갈대는 둑에 루트 Y=0으로 배치합니다. 수면 가까이 옮겨 일부를 잠기게 해도 됩니다.
징검돌은 장식/발판 메시이며 점프나 보행 AI를 자동으로 추가하지 않습니다.

물과 충돌
물은 불투명한 정적 색상 메시입니다. 물결·흐름·반사·투명 셰이더·수영은 없습니다.
물 표면에는 Collider가 없습니다. 잔디·둑·흙 밑면에는 MeshCollider가 있습니다.
물 아래 밑면은 Y=-0.45에서 충돌하므로 물에 들어갈 수 없도록 하려면
프로젝트의 NavMesh 영역 또는 이동 경로에서 수면을 제외해야 합니다.
다리는 MeshCollider를 사용해 경사로 모양을 따르며, 징검돌은 근사 BoxCollider입니다.
갈대는 시각 장식이며 충돌체가 없습니다. Rigidbody는 생성하지 않습니다.
다리·징검돌 위로 캐릭터가 움직이도록 하려면 기존 이동 시스템에 경로와 높이를 연결하세요.
NavMesh, 스폰, 적 이동 코드는 포함하지 않습니다.

파일
Models: OBJ 6종 / 공용 MeadowWater.mtl
Assets: Unity 프리팹 생성기 및 메시 JSON
Preview.png: 개별 크기를 맞춘 모델 카탈로그
SampleLayout.png: 직선 개울 3개, 다리, 징검돌, 갈대, 연못의 배치 예시

build_model.py / render_preview.py / render_layout.py: 재생성 소스
Python 3, numpy, scipy, Pillow로 소스 재생성이 가능합니다.
색상 재질을 사용하며 텍스처용 UV는 없습니다.

샘플 프리팹에는 개울·연못 타일과 소품만 포함합니다. 미리보기의 넓은 외곽
잔디 평면은 확인용이며 실제 씬에서는 기존 초원 타일 등으로 주변을 채우세요.
미리보기는 실제 메시의 소프트웨어 렌더이며 Unity 캡처가 아닙니다.
유한 좌표, 인덱스·삼각형 면적, 물 표면 높이·법선, 수면 충돌 제외,
물길 경계의 연결 방향 및 폭을 검증했습니다.
실제 Unity 에디터 컴파일·플레이와 캐릭터 통행 검증은 하지 못했습니다.
