AI Defenders 도시 건물 세트 - 제작 순서 06

설치
Assets/AIDefendersCityBuildings 폴더를 Unity 프로젝트 Assets에 복사합니다.
Tools > AI Defenders > Create City Buildings Kit 실행.
Assets/AIDefendersCityBuildingsGenerated에 모델 프리팹 3개와 예시 프리팹 1개 생성.

CityShop: 2층 상가, 청록색 간판/줄무늬 차양/쇼윈도/옥상 환기구. 높이 약 4.42유닛.
CityHouse: 2층 주택, 박공지붕/발코니/굴뚝/전면 계단. 높이 약 5.30유닛.
CityOffice: 5층형 업무 빌딩, 전후좌우 창/현관 캐노피/옥상 설비. 높이 약 9.45유닛.
CityBuildingsExample: 세 건물을 떨어뜨려 놓은 확인용 예시. 도로/인도/지형은 포함하지 않습니다.

배치
+Y 위, +Z 정면, 루트 Y=0이 건물 기초 바닥입니다.
기존 인도 높이는 .20유닛이므로 인도 위에 건물 기초를 놓을 때 루트 Y=.20으로 설정하세요.
도로 옆 인도 뒤쪽 대지에 배치할 때는 대지 높이에 맞춥니다.
주택 발코니, 상가 차양, 빌딩 캐노피가 본체보다 앞으로 돌출되므로 보행 공간을 확보하세요.
건물의 가로/깊이는 개별 크기이며 10유닛 타일 전체를 채우는 모듈은 아닙니다.
ModelInfo.json에 정확한 전체 경계와 삼각형 수를 기록했습니다.
높은 빌딩은 이동 경로나 포탑을 가리지 않는 맵 뒤쪽에 배치하는 것을 권장합니다.

배경용 외관 모델입니다. 실내/출입/문 개폐/발코니 보행/간판 텍스트/조명 애니메이션은 포함하지 않습니다.
유리는 불투명 색상 재질이며 실제 투명 창이 아닙니다.
단색 로우폴리 재질로 제작했으며 별도의 실사 텍스처는 없습니다.
건물 벽체/기초/지붕 위주로 정적 MeshCollider 적용. 작은 장식에는 충돌이 없습니다.
Built-in/URP 지원, HDRP는 별도 재질 설정.
OBJ 3개와 공용 MTL, Unity 생성기/메시 데이터, Python 소스, 프리뷰 포함.
Python 재생성에 numpy/Pillow 필요. Unity 사용에는 Python 불필요.
프리뷰는 개별 모델마다 배율이 다르며, 오른쪽 아래는 주택 후면입니다.
메시 인덱스/유한 좌표/퇴화 면 검사와 미리보기 확인 완료. Unity 내부 컴파일/실행은 미검증입니다.
