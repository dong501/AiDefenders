AI Defenders 도시 소품 세트 - 제작 순서 08

설치
Assets/AIDefendersCityProps 폴더를 Unity 프로젝트 Assets에 복사합니다.
Tools > AI Defenders > Create City Props Kit 실행.
Assets/AIDefendersCityPropsGenerated에 모델 프리팹 4개와 예시 배치 프리팹 1개 생성.

StreetTree: 가로수와 보호틀, 높이 약 3.55유닛. 보호틀 1.35x1.35유닛.
ParkBench: 목재 벤치와 금속 팔걸이, 폭 1.9/깊이 .73/높이 1.23유닛.
LitterBin: 원통형 쓰레기통, 높이 .94유닛. 입구는 얕게 들어간 장식 메시입니다.
Bollard: 노란 띠가 있는 볼라드, 높이 .84유닛.
CityPropsExample: 가로수/벤치/쓰레기통과 볼라드 4개를 함께 놓은 예시.
인도/도로/건물 자체는 포함하지 않습니다.

배치
+Y 위, 루트 Y=0이 소품 바닥입니다. 기존 인도 위에는 Y=.202에 배치하세요.
벤치 앞쪽은 +Z이며 쓰레기통 표찰도 +Z를 향합니다.
가로수 수관은 보호틀보다 넓으므로 건물/간판과의 간격을 확인하세요.
2유닛 폭 인도에서 나무와 벤치를 마주보게 놓으면 통행 공간이 좁아질 수 있습니다.
단색 재질의 로우폴리 외관 모델입니다. 바람 흔들림/앉기/쓰레기 투입/물리 파괴 코드는 포함하지 않습니다.
볼라드 노란 띠는 색상 재질이며 별도 반사/발광 효과가 없습니다.

Built-in/URP 재질 지원, HDRP 별도 설정.
나무 줄기/보호틀, 벤치 주요 부분, 쓰레기통 몸통, 볼라드 기둥에 정적 MeshCollider 적용.
나뭇잎과 작은 장식에는 충돌을 붙이지 않습니다.
OBJ 4개와 공용 MTL, Unity 생성기/메시 데이터, Python 소스, 미리보기 포함.
Python 재생성에 numpy/Pillow 필요. Unity 사용에는 Python 불필요.
프리뷰는 모델별 표시 배율이 다릅니다.
메시 인덱스/퇴화 면/유한 좌표 검사 및 프리뷰 확인 완료. Unity 내부 컴파일/실행 미검증.

계획한 1~8번 환경 모델 세트 제작 완료.
다음 작업 제안: 기존 도로/지형/건물/소품을 조합한 사막·도시 스테이지 배치.
