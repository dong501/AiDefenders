AI Defenders / 군용 천막·보급품 세트 6종

기존 막사, 격납고, 검문소와 어울리는 로우폴리 야전 보급 소품입니다.
천막, 보급 상자, 상자 적재형, 드럼통, 드럼 팔레트, 연료통을 각각 프리팹으로 생성합니다.
미리보기는 각 칸을 확대/축소한 것으로 상대 크기를 나타내지 않습니다.

[유니티 적용]
1. Assets/AIDefendersSupplyCamp 폴더 전체를 프로젝트 Assets에 복사.
2. 컴파일 완료 후 Tools > AI Defenders > Create Supply Camp Set 실행.
3. Assets/AIDefendersSupplyCampGenerated 아래 각 폴더의 프리팹을 씬에 배치.
메뉴 재실행 시 새 Generated 폴더를 만들어 기존 결과를 덮어쓰지 않습니다.
Built-in 및 URP용 재질을 생성하며 HDRP는 별도 재질 설정이 필요합니다.
기존 모델과 별도 클래스/폴더를 사용하므로 함께 가져올 수 있습니다.

[구성 / 삼각형 수]
FieldTent : 입구가 열린 군용 천막, 바닥/지지대/고정줄/말뚝 포함 / 1,332
SupplyCrate : 뚜껑/걸쇠/손잡이가 있는 보급 상자 / 364
CrateStack : 팔레트 위 상자 3개 적재 / 1,316
FuelDrum : 링/뚜껑/마개가 있는 드럼통 / 604
DrumPallet : 팔레트 위 드럼통 3개 / 2,036
JerryCan : 손잡이/마개/보강 리브가 있는 연료통 / 292
전체 합계 5,944 삼각형입니다.

[크기 및 배치]
+Y 위쪽 / 바닥 Y=0 / 천막 입구 및 상자 라벨 방향은 +Z.
천막 본체는 폭 약 4.28, 깊이 6.24, 높이 약 3.28입니다.
고정줄/말뚝을 포함한 전체 폭은 약 5.74이므로 옆에 공간을 남기세요.
천막 바닥 상단은 Y=.05, 입구 폭은 약 1.36, 중앙 입구 높이는 약 2.77입니다.
내부에 경비병, 상자 등을 배치할 수 있습니다. 내부 가구/조명/군인은 포함하지 않습니다.
천막은 낮은 측벽과 경사진 지붕이므로 벽 바로 옆에는 키 큰 캐릭터를 배치하지 마세요.
소품의 밑면을 맞출 때 천막 내부에서는 Y=.05에 배치하세요.
보급 상자 약 1.29 x .80 x .95, 상자 적재형 약 2.59 x 1.85 x 1.07.
드럼통 약 .67 x 1.02 x .68, 드럼 팔레트 약 1.60 x 1.27 x 1.65.
연료통 약 .45 x .76 x .30 Unity 단위입니다. 세부 크기는 ModelInfo.json 참조.

[충돌·동작]
모두 고정 배경 소품이며 천막 펄럭임, 입구 여닫기, 상자 뚜껑 열림, 마개 동작은 포함하지 않습니다.
천막 입구는 열린 상태 고정이고 벽/지붕/바닥을 개별 Convex MeshCollider로 구성해
안쪽 전체를 막는 큰 BoxCollider를 사용하지 않습니다.
고정줄·말뚝·지지대 등은 정밀 충돌을 따로 설정하지 않습니다.
나머지 소품은 전체 외곽을 감싸는 단순 BoxCollider를 사용합니다.
적재형의 빈 틈이나 드럼의 둥근 외곽과 충돌체가 정확히 일치하지는 않습니다.
Rigidbody, 운반/밀기 물리, 열기/획득, 자원 지급, 폭발/화재/파손, 보급 기능은 없습니다.
게임에서 보급품으로 활용하려면 상호작용, 자원량, 소모 등을 별도 코드에 연결하세요.
NavMesh/장애물 회피를 자동 설정하지 않으며 프로젝트의 이동 방식에 맞춰 설정해야 합니다.

[파일]
Assets/.../Editor : 메시 JSON 및 프리팹/머티리얼 생성기
Models/*.obj + SupplyCamp.mtl : 개별 소품 원본 (MTL은 OBJ와 같은 폴더에 유지)
Preview.png : 실제 메시의 소프트웨어 렌더링 미리보기 (유니티 캡처 아님)
ModelInfo.json : 원래 크기와 삼각형 수
build_model.py / render_preview.py : Python 생성 원본 (numpy, Pillow 필요)
단색 재질과 플랫 노멀을 사용하며 별도 텍스처 UV는 없습니다.

[확인 범위]
부품 이름, 면적, 인덱스, JSON/원본 정합성, 지면 기준과 천막 입구 공간을 검사하고
실제 모델 미리보기를 확인했습니다.
유니티가 없는 환경이라 유니티 컴파일/플레이, 내부 이동 및 물리 테스트는 수행하지 못했습니다.
