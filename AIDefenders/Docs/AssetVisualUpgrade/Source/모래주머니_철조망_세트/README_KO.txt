AI Defenders / 모래주머니·철조망 세트 6종

기존 군용 수송트럭, 검문소, 군인과 어울리는 고정 방어 소품입니다.
색을 칠한 로우폴리 메시로 구성했으며 각각 독립 프리팹으로 생성됩니다.
미리보기는 각 칸을 보기 좋게 확대/축소한 것으로 상대 크기를 나타내지 않습니다.

[유니티 적용]
1. Assets/AIDefendersFieldFortifications 폴더 전체를 프로젝트 Assets로 복사.
2. 컴파일 후 Tools > AI Defenders > Create Field Fortifications 실행.
3. Assets/AIDefendersFieldFortificationsGenerated 아래 각 폴더의 .prefab을 배치.
재실행하면 새 Generated 폴더가 생성되어 기존 결과를 덮어쓰지 않습니다.
Built-in 및 URP 재질을 생성하며 HDRP는 별도 설정이 필요합니다.
기존 모델과 별도 클래스/폴더를 사용하므로 함께 가져올 수 있습니다.

[구성 / 삼각형 수]
SandbagSingle : 단일 모래주머니 / 160
SandbagStraight : 4단 직선 벽, 엇갈린 적층 / 2,880
SandbagCorner : 4단 ㄱ자 벽 / 4,480
BarbedFence : 콘크리트 발판/기둥/가시 철선 / 1,512
WireCoil : 코일형 철조망과 말뚝 / 2,356
DamagedFence : 끊어지고 기울어진 철조망 / 420
전체 합계 11,808 삼각형입니다.
각 소품의 원래 크기는 ModelInfo.json을 참고하세요.

[배치 기준]
+Y 위쪽 / 바닥 Y=0. 모든 원본은 각각의 로컬 원점에 있습니다.
단일 모래주머니는 길이 X 약 .71 / 높이 .24 / 깊이 Z 약 .47입니다.
직선 벽은 X 길이 약 2.8 / 높이 .90이며 X 방향으로 약 2.8 간격 배치할 수 있습니다.
ㄱ자 벽은 가로 부분이 Z=0을 따라 놓이고 세로 부분은 X=-1.05에서 -Z 방향으로 뻗습니다.
Y축 회전으로 모서리 방향을 바꾸거나 직선 벽과 조합하세요.
기둥형 철조망의 기둥 중심 간격은 X=2.8, 높이는 약 1.98입니다.
철조망을 이어 붙일 때 중복 기둥과 발판이 겹칠 수 있습니다. 필요하면 해당 메시를 숨기거나 간격을 조절하세요.
코일은 X 방향 길이 약 3.0, 높이는 약 1.0입니다. 지형 경사에 맞춰 직접 조절하세요.

[충돌 및 게임 연결]
고정 환경 소품으로 애니메이션, 흔들림, 피격/파괴 전환은 포함하지 않습니다.
일반 소품은 전체 외곽을 감싸는 단순 BoxCollider입니다.
ㄱ자 모래주머니는 두 벽을 각각 감싸는 BoxCollider 2개를 사용해 안쪽 빈 공간을 남깁니다.
철조망의 충돌체는 철선 사이 빈 공간도 막습니다. 파손 철조망도 기본 박스 충돌체를 사용하므로
장식으로만 쓰거나 틈으로 통과시키려면 Collider를 끄거나 직접 수정하세요.
NavMeshObstacle, 경로 차단, 엄폐 판정, 피해, 감속, 체력, 피아식별 기능은 없습니다.
물리 충돌만으로 기존 Transform 이동 차량이 자동 정지하는 것은 아닙니다.
게임 이동/길찾기 시스템에 맞춰 장애물을 등록하고 필요하면 NavMesh를 다시 구우세요.
Rigidbody는 포함하지 않습니다. 움직이는 파편 물리가 필요하면 별도로 구성해야 합니다.

[파일]
Assets/.../Editor : 데이터 JSON 및 프리팹/머티리얼 생성기
Models/*.obj : 개별 소품 원본 메시
Models/FieldFortifications.mtl : 공용 색상 재질 (OBJ와 같은 폴더에 유지)
Preview.png : 실제 메시의 소프트웨어 렌더링
ModelInfo.json : 각 모델 크기/삼각형 수
build_model.py / render_preview.py : Python 생성 원본 (numpy, Pillow 필요)
단색 재질과 플랫 노멀을 사용하며 별도 이미지 텍스처나 텍스처 UV는 없습니다.
소품이 많은 씬에서는 재질별 메시 결합 등 프로젝트에 맞는 최적화를 적용할 수 있습니다.

[확인 범위]
부품 이름, 면적, 인덱스, JSON/원본 좌표 정합성과 지면 기준을 검사하고
실제 모델의 소프트웨어 렌더링 미리보기를 확인했습니다.
유니티가 없는 환경이라 유니티 컴파일/플레이 및 물리/길찾기 테스트는 수행하지 못했습니다.
