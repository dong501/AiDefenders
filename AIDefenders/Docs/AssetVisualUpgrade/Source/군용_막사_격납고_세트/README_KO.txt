AI Defenders / 군용 막사·차량 격납고 세트

기존 군용 차량, 군인, 검문소와 어울리는 로우폴리 기지 건물입니다.
MilitaryBarracks와 VehicleHangar의 프리팹 2종을 생성합니다.
막사는 외관용 고정 건물이며, 격납고는 내부 바닥과 개폐문이 있어 차량 배치/통과가 가능합니다.
미리보기는 각 건물을 확대/축소한 것으로 상대 크기를 나타내지 않습니다.

[유니티 적용]
1. Assets/AIDefendersBaseBuildings 폴더 전체를 프로젝트 Assets에 복사.
2. 컴파일 후 Tools > AI Defenders > Create Base Buildings 실행.
3. Assets/AIDefendersBaseBuildingsGenerated 아래의 각 폴더에서 프리팹을 씬에 배치.
4. Play에서 격납고 문은 기본 Auto Demo로 여닫기를 반복합니다.
생성 메뉴를 다시 실행하면 새 Generated 폴더를 만들어 기존 결과를 덮어쓰지 않습니다.
Built-in 및 URP 머티리얼을 생성하며 HDRP는 별도 재질 설정이 필요합니다.
기존 모델과 별도 클래스/폴더를 사용합니다.

[군용 막사]
MilitaryBarracks / 1,960 삼각형.
박공지붕, 양옆 창문, 현관 차양/계단, 배수관, 환기구를 포함합니다.
약 폭 5.4 x 높이 4.21 x 길이 8.85 Unity 단위입니다.
단순 외관용 건물로 실내와 문 열림 동작이 없으며, 전체 외곽의 BoxCollider를 사용합니다.
사람이 안으로 들어가도록 만들어진 건물은 아닙니다.

[차량 격납고]
VehicleHangar / 2,764 삼각형.
분절 곡면 지붕, 보강 리브, 측창, 옆 출입문 장식, 차량용 개폐문, 바닥/진입 경사로를 포함합니다.
본체는 약 폭 8.9 x 높이 5.8 x 깊이 10.6, 경사로 포함 앞뒤 범위는 Z=-5.3~6.5입니다.
정면은 +Z, 입구 유효 폭은 약 7.2, 입구 상단은 Y=4.2입니다.
실내 바닥은 Y=.2이며 문이 완전히 열렸을 때 아래쪽 높이는 약 Y=4.04입니다.
기존 군용 수송트럭(높이 약 3.16)과 장갑차가 들어갈 수 있는 기하학적 공간을 두었습니다.
내부에 정비 장비/가구/병력은 포함하지 않습니다.
옆 출입문은 장식이며 열리지 않습니다.

[격납고 문 제어]
HangarDoor 컴포넌트에서 Auto Demo 기본 켜짐.
닫힘 2초 대기 → 1.4초 열기 → 열림 2초 대기 → 1.4초 닫기 반복합니다.
문 전체가 상단 경첩을 중심으로 실내 쪽으로 올라가는 단일 패널 방식입니다.
감겨 올라가는 롤러 셔터나 여러 조각으로 접히는 문은 아닙니다.
Start Open : 처음부터 열린 상태. Travel Seconds : 개폐 시간. Dwell Seconds : 자동 시연 대기 시간.
Open Angle 기본 90도. 다른 각도로 낮추면 통과 높이가 줄어듭니다.
게임 코드에서 Open(), Close(), Toggle(), SetOpen(true/false)를 호출할 수 있습니다.
메서드 호출 시 Auto Demo가 꺼져 외부 명령으로 제어됩니다.
IsOpen은 완전히 열렸을 때, IsMoving은 개폐 중일 때 true입니다.
진행 도중 반대 명령을 주면 현재 위치에서 반대 방향으로 이동합니다.
문에는 Kinematic Rigidbody와 BoxCollider를 연결하고 FixedUpdate의 MoveRotation으로 움직입니다.
Animator/AnimationClip 방식은 아닙니다.
자동 차량 감지, 장애물 감지, 출입 권한, 정비 기능, 소리는 없습니다.
문이 움직이는 실내 상단 공간에 차량이나 물건을 두지 마세요.

[차량 이동·충돌 연결]
격납고 전체를 막는 큰 충돌체 대신 바닥, 양측 벽, 뒷벽, 정면 기둥/문 상단,
움직이는 문에 나눠 충돌체를 둡니다. 경사로는 Convex MeshCollider입니다.
지붕 충돌체는 상단의 단순 평판 근사치로 곡면과 정확히 일치하지 않습니다.
차량을 내부 바닥에 놓을 때는 차량 루트 Y를 .2로 설정하세요.
기존 차량의 Transform 이동은 지면/경사로 높이를 자동으로 따라가지 않습니다.
차량 경유점 Y를 경사로의 지면 0에서 내부 바닥 .2로 바뀌게 배치하거나,
프로젝트의 지면 추종/차량 이동 시스템에 연결하세요.
외부 이동 로직에서 문 앞에 차량을 정지시키고 Open()을 호출한 뒤
IsOpen이 true일 때 이동을 재개하도록 연결할 수 있습니다.
문을 닫기 전에는 차량 전체가 문 회전 범위에서 벗어났는지 게임 코드에서 확인해야 합니다.
충돌만으로 이전 차량의 Transform 이동이 자동 정지하지는 않습니다.
NavMesh 설정, 장애물 회피, 차량 물리, 배경 조명은 포함하지 않습니다.
격납고 루트는 배치 후 고정하고 균등 스케일을 사용하는 것을 권장합니다.

[좌표와 파일]
+Y 위쪽 / +Z 건물 정면 / 지면 Y=0.
DoorPivot은 루트 기준 (0,4.2,5.18), 로컬 +X축으로 +90도 회전하면 열립니다.
Assets/.../Editor : 메시 JSON 및 프리팹/재질 생성기
Assets/.../Runtime : HangarDoor.cs
Models/*.obj + BaseBuildings.mtl : 정지 메시 원본. OBJ에는 계층/개폐 스크립트가 없습니다.
Preview.png : 두 건물의 실제 메시 미리보기
HangarOpen.png / HangarDoorPreview.gif : 실제 격납고 메시의 열림 상태/개폐 미리보기
미리보기는 유니티 녹화가 아닌 소프트웨어 렌더링입니다.
ModelInfo.json : 실제 크기와 삼각형 수
Python 생성/렌더링 원본 : numpy/Pillow 필요.
단색 재질/플랫 노멀을 사용하며 텍스처용 UV는 없습니다.

[확인 범위]
면적, 부품 이름, 인덱스, JSON/원본 정합성, 문 피벗과 통과 공간의 치수를 검사하고
건물과 문 개폐 미리보기를 확인했습니다.
유니티가 없는 환경이라 유니티 컴파일/플레이, 차량 통과 물리 및 길찾기 테스트는 수행하지 못했습니다.
