AI Defenders / 검문소·차단기 세트

기존 군용 수송트럭, 장갑차, 군인과 어울리는 로우폴리 기지 입구 소품입니다.
경비 초소, 개폐 차단기, 콘크리트 방호벽, 안내 표지판의 개별 프리팹 4종과
이들을 미리 배치한 CheckpointLayout 프리팹을 생성합니다.
도로 바닥은 포함하지 않으므로 기존 도로 위에 배치하세요.

[유니티 적용]
1. Assets/AIDefendersCheckpoint 폴더 전체를 프로젝트 Assets에 복사.
2. 컴파일 후 Tools > AI Defenders > Create Checkpoint Set 실행.
3. Assets/AIDefendersCheckpointGenerated/CheckpointLayout.prefab을 씬에 배치.
4. Play를 누르면 기본 Auto Demo가 차단기를 여닫습니다.
개별 소품은 각 하위 폴더의 .prefab을 사용하면 됩니다.
메뉴 재실행 시 새 Generated 폴더가 생성되어 기존 결과를 덮어쓰지 않습니다.
Built-in 및 URP 재질을 생성합니다. HDRP는 별도 재질 설정이 필요합니다.

[구성]
GuardBooth : 경비 초소, 창문/문/지붕/발판/전등 / 896 삼각형
BarrierGate : 구동함, 차단봉, 받침 기둥, 상태 표시등 / 776 삼각형
ConcreteBarrier : 독립 배치형 콘크리트 방호벽 / 340 삼각형
CheckpointSign : 독립 배치형 표지판 / 196 삼각형
개별 4종 합계 2,208 삼각형. 조립형은 방호벽 2개를 사용하므로 2,548 삼각형입니다.
초소 크기 약 3.03 x 2.93 x 2.75 단위 (발판 포함).
차단봉 길이 약 5.2 단위, 피벗 높이 1.17, 개방 각도 기본 85도.
열렸을 때 높이가 약 6.35까지 올라가므로 위쪽에 공간을 두세요.
차단기 기본 전방은 +Z, 봉은 +X 방향으로 뻗고 로컬 +Z축 주위로 회전합니다.
표지판은 문자가 아닌 줄무늬 장식으로 별도 텍스처 없이 제작했습니다.

[차단기 조작]
BarrierGate의 CheckpointBarrier 컴포넌트를 사용합니다.
Auto Demo : 기본 켜짐. 닫힌 상태 2초 대기 → 1.4초 열기 → 열린 상태 2초 대기 → 1.4초 닫기 반복.
Start Open : 처음부터 열린 상태로 시작할 때 사용.
Travel Seconds : 개폐 시간. Dwell Seconds : 자동 시연에서 완전히 열린/닫힌 상태의 대기 시간.
Open Angle : 봉이 올라가는 각도.
게임 코드에서는 다음을 호출할 수 있습니다.
  Open() : 열기
  Close() : 닫기
  Toggle() : 목표 개폐 상태 전환
  SetOpen(true/false) : 개폐 상태 지정
메서드 호출 시 Auto Demo가 꺼져 이후 게임 코드로 제어됩니다.
IsOpen은 완전히 열렸을 때 true, IsMoving은 개폐 중일 때 true입니다.
진행 도중 반대 명령을 주면 현재 위치에서 반대 방향으로 움직입니다.
상태 표시등은 닫힘=빨강, 개폐 중=주황, 완전 개방=초록입니다. 실제 광원은 아닙니다.
Animator/AnimationClip 대신 런타임 스크립트로 움직입니다.
차단봉에는 Kinematic Rigidbody와 BoxCollider가 연결되며 FixedUpdate에서 MoveRotation으로 움직입니다.
모델의 시연 및 영상은 봉의 움직임과 표시등 동작을 보여줍니다.

[충돌·게임 로직]
초소·방호벽·표지판에는 단순 BoxCollider가 있습니다. 초소는 들어갈 수 없는 닫힌 배경 소품입니다.
차단기는 차로 전체를 덮는 고정 박스를 쓰지 않고 구동함/받침/움직이는 봉을 따로 구성했습니다.
Counterweight의 정밀 충돌 형태는 구현하지 않습니다.
자동 차량 감지, 번호판/피아식별, 접근 권한 판정, 차량 정지/출발, NavMesh 통행 제어,
닫힘 경로의 장애물 감지, 소리, 문 열림, 실내 모델은 포함하지 않습니다.
차량이 앞에 있으면 외부 게임 로직에서 차량 이동을 멈추고 Open()을 호출하세요.
IsOpen이 true일 때 차량을 출발시키고 차량 전체가 지나간 후 Close()를 호출하도록 연결하면 됩니다.
닫힘 시 차량이나 캐릭터가 없는지는 게임 코드에서 확인해야 합니다.
이전 차량 키트의 Transform 이동은 충돌 때문에 자동으로 멈추지 않습니다.
애니메이션/물리 안정성을 위해 차단기 루트는 배치 후 고정하고 균등 스케일을 권장합니다.

[조립형 배치]
초소 X=-4.65 / 차단기 X=-2.58 / 우측 방호벽 X=4.10 / 표지판 X=3.25.
차단기 기준점은 구동함 바닥이며 조립형에서는 봉이 차로를 좌우로 가로막습니다.
개별 프리팹을 원하는 위치로 옮기고 회전해 도로 폭에 맞춰 배치할 수 있습니다.

[파일]
Assets/.../Editor : 메시 JSON 및 프리팹/재질 생성기
Assets/.../Runtime : CheckpointBarrier.cs
Models/*.obj + Checkpoint.mtl : 개별 모델 정지 원본. OBJ에는 피벗 계층/개폐 스크립트가 없습니다.
Preview.png / OpenPreview.png : 조립형 검문소의 닫힘/열림 상태
GatePreview.gif : 실제 메시의 개폐 소프트웨어 렌더링 (유니티 녹화 아님)
ModelInfo.json : 개별 크기/삼각형 수
Python 생성/렌더링 원본 : numpy, Pillow 필요.
단색 재질 및 플랫 노멀을 사용하며 텍스처용 UV는 없습니다.

[확인 범위]
부품 이름, 면적, 인덱스, 차단봉 로컬 좌표와 피벗 연결을 검사하고
닫힘/열림 및 개폐 미리보기를 확인했습니다.
유니티가 없는 환경이라 유니티 컴파일/플레이 및 물리 상호작용 테스트는 수행하지 못했습니다.
