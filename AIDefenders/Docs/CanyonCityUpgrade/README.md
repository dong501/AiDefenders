# 사막 협곡 / 도시 건물 업그레이드

## 적용

- 사막: 두 개의 지층 절벽과 14~17m 높이의 포탑 설치 고지대 4곳, 원경 메사 6개, 사암 표면 질감. 기존 전초기지와 선인장을 유지하고 일부 장식은 지형 높이에 맞춰 배치했습니다.
- 사막 드론 시작 위치를 높여 협곡을 내려다보도록 조정했습니다.
- 도시: 제공된 건물 메시 자료 36종을 임포트하고, 기존 32개 건물을 서로 다른 32종으로 교체했습니다. 외곽에는 약 64~89m 높이의 업무용 고층 건물 8개를 추가했습니다.
- 도시 중앙 대피소, 경찰차·구급차, 수목과 4방향 방어 구조를 유지했습니다.
- 재적용 도구: `Assets/Scripts/Editor/CanyonAndCityVisualUpgrade.cs`, Unity 메뉴 `Tools/AI Defenders/Environment Expansion/7 Canyon And City Skyline`.
- 작업 전 씬·사막 TerrainData와 선택 화면 미리보기는 `Before`에 보관했습니다.

## 촬영 사진

`Photos` 폴더에 UI 없는 1920×1080 PNG 6장:

1. `Desert_01_Overview.png`: 협곡 및 전초기지 전경
2. `Desert_02_Canyon_Floor.png`: 협곡 바닥에서 본 절벽
3. `Desert_03_HighGround_Turret.png`: 고지대에 포탑을 설치한 배치 예시. 촬영용으로 배치한 포탑은 촬영 후 제거했으며 시작 시 자동 지급되는 포탑이 아닙니다.
4. `City_01_Skyline.png`: 다양한 건물과 고층 스카이라인
5. `City_02_Shelter.png`: 중앙 대피소 전경
6. `City_03_Street.png`: 거리에서 본 건물 외관

`Desert_City_Photos.zip`에 원본 사진과 `All_Photos.jpg` 미리보기를 함께 묶었습니다.

## 확인한 내용

- Unity 컴파일 오류 없음.
- 사막의 실제 사용되는 두 경로를 약 2m 간격, 총 212지점에서 검사: 새 지형이 이동로를 가리는 지점 없음.
- 고지대 4곳의 건설용 지면 Raycast 성공. 아래 이동로로 향하는 사선 차단 없음, 검사 거리 약 19~23m로 정밀 사격 포탑의 25m 사거리 이내.
- 도시의 기존 스포너·경로·목표·카메라 Transform 서명이 건물 교체 전후 동일함.
- 사막·도시를 Play 모드에서 각각 열고 준비 단계 카메라 및 HUD 표시, 도시 건물 40개와 4개 스포너 존재를 확인. 콘솔 오류 없음.
- 전체 웨이브 클리어와 AI 서버를 연결한 실전 밸런스 검증은 이번 확인 범위에 포함하지 않았습니다.
