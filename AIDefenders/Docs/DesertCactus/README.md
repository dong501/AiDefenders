- 원본: 제공 ZIP의 사막 탐사유적 에셋, DesertBranchedCactus.
- 세로 능선과 작은 가시를 더한 가지형·키 큰 형태·어린 선인장 3종을 생성했습니다. 어린 개체 일부에는 작은 황토색 꽃을 추가했습니다.

- 기존 Cacti 루트는 비활성 상태로 보관하고 새 배치는 Desert_Cactus_Upgrade에 묶었습니다.
