# UI 참고 자료 적용

참고 이미지: 첨부된 WebP 60장. 파란 패널, 어두운 외곽선, 입체 버튼, 강조색과 카드 구성을 게임 UI에 적용했습니다.

- 메인 메뉴: 실제 포탑 렌더와 노란 캠페인 시작 버튼.
- 챕터 → 스테이지: 실제 초원/사막/도시 맵 미리보기 카드. 제작된 5개 스테이지의 기존 선택 조건 유지.
- 포탑 연구소: 공통 스타일, 넓어진 연구 패널, 연구 포인트 강조, 한글 이동 버튼.
- 전투: 상태 패널, 건설 UI, 모델 선택, 스킬 슬롯에 공통 스타일 적용.
- 결과/로딩: 금색 결과 헤더, 연구 포인트 영역, 초록 메뉴 버튼, 금색 로딩 진행 바.

`UiSkin.cs`와 `UiSurfaceGradient.cs`에서 색상과 표면 스타일을 관리합니다. 맵/포탑 미리보기는 프로젝트의 실제 모델과 씬으로 렌더한 `Assets/Resources/UI/Previews`를 사용합니다. 참고 이미지의 상점이나 결제 기능을 추가하지 않았습니다.

검증: Unity 컴파일 오류 0건. 메인 캠페인 버튼, 챕터/스테이지 전환, 연구소 포탑 4종 목록과 단계 미리보기 버튼, 성공/실패 결과 표시, 초원 전투 HUD 생성 확인. 확인 중 Console 오류 0건. 연구 포인트를 소비하거나 저장 데이터를 변경하지 않았습니다. 전체 전투 및 YOLO 서버의 정확도 검증은 이번 UI 확인에 포함되지 않습니다.

PNG는 1920×1080 UI 확인용 캡처입니다. Result.png는 실패 결과를 주입한 표시 확인용 화면입니다.

## 추가 참고 이미지 5장 적용

- 전투 상단의 기지 체력/자금/점수/라운드 패널을 작게 분리했습니다.
- Tab 건설 메뉴를 오른쪽 2열 포탑 카드로 변경하고 실제 1단계 포탑 렌더와 가격을 표시합니다. 보관 포탑은 왼쪽 하단에 배치했습니다.
- Esc 또는 상단 Ⅱ 버튼으로 일시정지합니다. 전체 음량, 계속하기, 다시 시작, 메인 메뉴 이동을 지원합니다. 정지 중 카메라/건설/스킬 입력을 막고, 계속하기와 화면 이동 시 시간 배율 및 커서를 복원합니다.
- 메인 화면에는 실제 초원 맵을 배경으로 추가했습니다.

검증: 컴파일 및 UI 점검 중 Console 오류 0건. 카드 클릭 시 배치 시작 및 확정 전 자금 유지, 정지 중 준비 시간 고정, 계속하기 시 시간 배율 1 복원, 음량 슬라이더 연결, 재시작 및 메인 메뉴 복귀 확인. 모델 학습/서버 실행이나 연구 포인트 변경 없이 UI를 점검했습니다.
