- 한국어 자막을 영상에 직접 표시했습니다. 음성·배경음악은 없습니다.

- 촬영 중 학습 실행, 외부 서버 실행, 연구 포인트 소비는 하지 않았습니다. 촬영 후 메인 메뉴로 복귀했습니다.
